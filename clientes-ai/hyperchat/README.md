# Configuração para HyperChat

HyperChat é um cliente desktop nativo para macOS/Windows.

## Configuração

1. Abra as **Preferências** (Settings).
2. Vá na aba **MCP Servers**.
3. Clique em **+**.
4. Selecione o tipo **Streamable HTTP** (em versões antigas, use **SSE**).
5. URL: `https://mcp.apibrasil.cloud/mcp`
6. Clique em **Connect**.
